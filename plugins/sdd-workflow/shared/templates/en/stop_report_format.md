# Stop Report Format

## Clarification Process Complete

### Final Clarity Score: {score}%

### Resolved Questions: {resolved}/{total}

### Remaining Unclear Points (if any)

- {unresolved item 1}: {impact scope}
- {unresolved item 2}: {impact scope}

### Recommended Action

- {Score 80%+}: Ready for implementation
- {Score 60-79%}: Proceed with implementation understanding the following risks, or continue clarification
- {Score 40-59%}: Significant specification revision needed before implementation
- {Score <40%}: Do not start implementation; rebuild the specification
    - Risk 1: {specific risk}
    - Risk 2: {specific risk}
